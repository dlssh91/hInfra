# OS 가상화(osvirt) 35항목 사전 라벨분류 제안 (§4-3)

> 작성: 2026-07-11. 근거: `item_configs/osvirt.yaml`(현재 스캐폴드, 전 항목 기본 label A)
> + `ref/전자금융기반시설 보안 취약점 평가기준(제2026-1호) 평가자용_2603개정.xlsx`
> ("OS 가상화 시스템" 시트, ESXi 기준 컬럼 — 35항목 슈퍼셋) 판단기준/판단방법 원문 정독.
>
> **주의: 이 문서는 제안뿐이다. `judge_tool/item_configs/osvirt.yaml`은 수정하지 않았다**
> (사용자 결정 대기 — 작업 지시 §4-3 "yaml 수정 금지"). 실수집 샘플 확보 전이므로
> 판단기준 원문(정적 텍스트)만으로 분류한 것이며, 실데이터로 검증되지 않았다.

## 방법론

- label 정의는 `osvirt.yaml` 스캐폴드 주석과 동일: A=기술증거 LLM판정,
  B=인터뷰 필수(판단보류 고정), C=기술적 한계(canned, LLM 미호출), D=외부지식
  (EOL/패치, canned, LLM 미호출).
- 1차 근거: PRCV 항목의 판단기준/판단방법 원문에 "인터뷰/업무상 확인 필요/
  내부 규정" 등 자동판정 불가 신호가 있는지.
- 2차 근거(교차검증): 서버 도메인(`item_configs/server.yaml`)에 **동일 항목명**의
  SRV 항목이 존재하면 그 label 결정을 참고한다(같은 평가기준 체계·같은 판정팀
  설계 원칙을 공유하므로 유효한 신호). 단, 판단방법(검증 절차)이 다르면
  기계적으로 복사하지 않고 별도 명시한다(아래 PRCV-004 사례 참조).
- 패치/EOL(D) 후보: 35항목 전수 검토 결과 **하이퍼바이저 패치·버전 확인 항목
  자체가 OS 가상화 시트에 없음**(서버 도메인의 SRV-007/064/179류에 대응하는
  PRCV 항목 부재). 설계문서 §4-3의 "패치성=D" 힌트는 확인 결과 **해당 없음**으로
  결론 — 후속 개정판에 패치 관련 항목이 추가되면 그때 D 후보로 재검토.

## 변경 제안 요약

**35항목 중 3항목(PRCV-003, PRCV-022, PRCV-023)에 대해 label B(인터뷰) 전환을
제안**한다. 나머지 32항목은 현행 유지(label A)를 제안한다. D 후보는 없음(위 근거).
C 후보도 없음(아래 "검토했으나 채택 보류" 참조 — PRCV-025는 수집 스크립트
보강 대상이지 라벨 문제가 아님).
